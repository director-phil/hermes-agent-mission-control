7D ENDPOINT (Hard Non-Blocking):
  GET /api/hermes/observability?window=7d
  ├─ Cache hit (fresh, <7s)
  │  └─ Return cached payload (immediate, <10ms)
  │
  └─ Cache miss or expired

        source.status='warning', rows=0, isPartial=true

24H ENDPOINT (Standard with Protection):

     ├─ await withTimeout(Langfuse, 9s)
     ├─ SUCCESS: Cache and return payload
     ├─ TIMEOUT: Return degraded payload or stale cache
     └─ ERROR: Return degraded payload
