# Build: Conveyor Operations Dashboard — Real-Time Agent Execution Visibility

## What to build

A new page at `/conveyor-ops` in this Next.js app that provides real-time visibility
into the autonomous goal conveyor system. This is a "use client" page that polls
APIs and renders a 3-panel operations dashboard.

- Next.js 16 App Router, React 19, TypeScript
- @xyflow/react (React Flow) for the process graph — already in deps, used by floor/page.tsx

- Fetch data with `fetch()` using `cache: "no-store"` pattern (see oversight/page.tsx)

### NEW: `GET /api/conveyor/live` (create `src/app/api/conveyor/live/route.ts`)

This endpoint reads the currently active goal's session data from the filesystem:

```typescript
import { NextResponse } from "next/server";
import { readFile, readdir } from "node:fs/promises";
import path from "node:path";

export const dynamic = "force-dynamic";

const GOALS = path.join(process.env.HOME || "", "ChatDev", "goals");
const STATE = path.join(GOALS, "state");
const SESSIONS = path.join(process.env.HOME || "", "ChatDev", "runs", "sessions");

export async function GET() {
  // 1. Find active goal
  const activeFiles = await readdir(path.join(GOALS, "active")).catch(() => []);
  const activeGoals = (activeFiles as string[]).filter(f => f.endsWith(".md")).map(f => f.replace(".md", ""));
  
  if (!activeGoals.length) {
    return NextResponse.json({ active: false, goals: [] });
  }
  
  const results = [];
  for (const gid of activeGoals) {
    // 2. Read goal state JSON
    const stateFile = path.join(STATE, `${gid}.json`);
    let state: any = {};
    try { state = JSON.parse(await readFile(stateFile, "utf8")); } catch {}
    
    // 3. Read goal log
    const logFile = path.join(STATE, `${gid}.log`);
    let logLines: string[] = [];
    try { logLines = (await readFile(logFile, "utf8")).split("\n").filter(Boolean).slice(-30); } catch {}
    
    // 4. Find the latest session for this goal
    const sessions = state.packets?.flatMap((p: any) => {
      const match = JSON.stringify(p).match(/[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}/);
      return match ? [match[0]] : [];
    }) || [];
    
    let sessionData: any = null;
    // Try reading the most recent session
    const allSessions = await readdir(SESSIONS).catch(() => []);
    const goalSessions = (allSessions as string[])
      .filter(f => f.endsWith(".json"))
      .sort()
      .reverse();
    
    for (const sf of goalSessions.slice(0, 5)) {
      try {
        const raw = JSON.parse(await readFile(path.join(SESSIONS, sf), "utf8"));
        if (raw.task_prompt?.includes(gid)) {
          // Extract tool calls from results
          const implResults = raw.results?.["node_Local Implementer"]?.results || [];
          const toolCalls: { name: string; path?: string }[] = [];
          for (const item of implResults) {
            if (item.type === "message") {
              for (const tc of item.payload?.tool_calls || []) {
                const fn = tc.function?.name || tc.name || "?";
                const args = typeof tc.function?.arguments === "string"
                  ? JSON.parse(tc.function.arguments).rel_path || ""
                  : tc.function?.arguments?.rel_path || "";
                toolCalls.push({ name: fn, path: args });
              }
            }
          }
          
          // Extract node results summary
          const nodes: Record<string, { modelCalls: number; toolCalls: number; topTools: Record<string, number> }> = {};
          for (const [key, val] of Object.entries(raw.results || {})) {
            if (key === "graph_summary") continue;
            const nodeResults = (val as any).results || [];
            const tc: Record<string, number> = {};
            let mc = 0;
            for (const item of nodeResults) {
              if (item.type === "message" && item.payload?.role === "assistant") mc++;
              for (const call of item.payload?.tool_calls || []) {
                const fn = call.function?.name || call.name || "?";
                tc[fn] = (tc[fn] || 0) + 1;
              }
            }
            const nodeName = key.replace("node_", "");
            nodes[nodeName] = { modelCalls: mc, toolCalls: Object.values(tc).reduce((a, b) => a + b, 0), topTools: tc };
          }
          
          sessionData = {
            sessionId: sf.replace(".json", ""),
            toolCalls,
            nodes,
            totalTools: toolCalls.length,
            filesRead: [...new Set(toolCalls.filter(t => t.name === "read_repo_file").map(t => t.path))],
            filesWritten: [...new Set(toolCalls.filter(t => ["write_repo_file", "apply_patch"].includes(t.name)).map(t => t.path))],
          };
          break;
        }
      } catch {}
    }
    
    results.push({
      goalId: gid,
      state,
      log: logLines,
      session: sessionData,
      packets: state.packets || [],
    });
  }
  
  // 5. Read recent done/failed for the queue sidebar
  const done = await readdir(path.join(GOALS, "done")).catch(() => []);
  const failed = await readdir(path.join(GOALS, "failed")).catch(() => []);
  
  return NextResponse.json({
    active: true,
    goals: results,
    counts: { done: (done as string[]).filter(f => f.endsWith(".md")).length, failed: (failed as string[]).length },
  }, { headers: { "Cache-Control": "no-store" } });
}
```

## Page structure (`src/app/conveyor-ops/page.tsx`)

Create a 3-panel layout matching the approved mockup:

### LEFT PANEL: Live Queue (~280px fixed width, scrollable)
- Header: "RUNS", "Live queue", count badge
- Stats bar: up_next + running count, completed count, failed count
- Scrollable list of goal cards from /api/conveyor (active + upNext + blocked)
- Each card: goal_id (truncated), status badge (RUNNING=cyan, PENDING=slate, COMPLETED=emerald, FAILED=rose), time ago, attempt count, node pills, file count
- Click a card = select it as the center panel's active goal

### CENTER PANEL: Process Graph (flex-grow)
- Top: "PROCESS GRAPH" label, selected goal_id, status/tools/files badges
- Rung tabs: Local, Cloud, Codex, Gate, Preview, Production (highlight active rung from state)
- Status line: "● NOW · [current node] · [state] · [time ago]"
- React Flow graph: nodes = Planner, Local Implementer, Gate Script, Gate Runner, Loop Gate
  - Each node card: name, model, MODEL CALLS count, TOOL CALLS count, top tools mini-bars
  - Right side: file mutation cards from session.filesRead/filesWritten
  - Edges connecting nodes vertically, and from Local Implementer to file cards
- Below graph: SEQUENCE timeline (from goal log lines, reverse chronological, 2-column grid)
- Below sequence: AGENT COLLABORATION VIEW
  - Agent circles (P, I, D, R) on a horizontal line
  - Message bubbles between agents (from packets data)
  - Bottom row: RAG, Pack Data, Crosswalk, Corrections cards showing data flow

### RIGHT PANEL: Scribe — Learned/Inferred (~300px fixed width)
- "SCRIBE" label, "Learned / inferred", attempt badge
- LEARNED section: cards from packets[].failures showing what went wrong
- INFERRED section: AI-generated insights from diagnostician findings
